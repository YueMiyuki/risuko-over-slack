# risuko-over-slack

A Slack bot that integrates with the Risuko download manager, allowing you to manage downloads directly from Slack.
Download - and send back compressed

Written in Node.js using the @slack/bolt framework

## Installation
1. Clone the repository
2. Install dependencies
   ```bash
   npm install
   ```
3. Create a `.env` file based on the provided `.env.example` and fill in your Slack app credentials and other configurations.
4. Start the bot
   ```bash
   npm start
   ``` 
5. Enjoy :)
